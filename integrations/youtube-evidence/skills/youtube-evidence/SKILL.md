# Selma° YouTube Evidence Research

1. Search YouTube public metadata for relevant titles and watch links. Metadata is not footage.
2. Record source URL, author/channel, publication date and useful timestamp links.
3. Inspect actual video frames/audio using authorized media tools or user-supplied recordings. If no tool watched the video, explicitly state "not viewed" and avoid visual claims.
4. Separate directly observed events from narration, interpretations and hypotheses.
5. For subwoofer levitation claims, check possible airflow, vibration/bounce, supports, editing, camera effects and controlled force measurements. Use reproducible tests without presuming either a positive or negative conclusion.
6. Assess mass, duration, trajectory and a continuous multi-angle source when possible.
7. Preserve evidence provenance and avoid alterations to originals. Mark uncertain claims unverified.
8. Don't scrape restricted captions, obtain private videos without permission, invent timestamps, or misrepresent tool abilities.
