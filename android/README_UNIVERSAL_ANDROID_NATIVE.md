# Selma Universal Android Native Overlay

Practical compatibility target: Android 6.0/API 23 through API 35, manufacturer-neutral Android framework APIs, no ARCore, no Google Play Services, no Unity, no NDK architecture lock, OpenGL ES 2.0 with automatic 2D fallback, and low-RAM quality reduction.

No APK can guarantee every Android device, custom ROM, enterprise policy, TV, watch, automotive build, or manufacturer restriction. Overlay permission can also be blocked by the user or device administrator.

This remains a universal native overlay alpha with a procedural 3D placeholder. A photorealistic Selma still requires an optimized model pipeline and device testing.
