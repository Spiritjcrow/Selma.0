# Flipp'n Da Table! — FDT Gate v0.7

Operational reference runtime for framework-neutral AI action authorization. The model proposes an Action Envelope; WingDingynouse HARDSTONE verifies signed policy, scoped/expiring/revocable capability, exact-action approvals, budgets, and emits a signed decision receipt before host execution.

Security rule: unusual FDT Key Grammar is expressive language identity, not an authorization boundary. Possessing input influence or understanding the language does not grant authority to execute a protected effect.
