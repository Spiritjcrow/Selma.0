Command reference

Run inside the appropriate macOS/Linux runner with Android SDK configured, not a fresh Termux shell without the SDK.

cd SELMA0_ANDROID_NATIVE_V1
./gradlew --no-daemon \
  :app:lintDebug \
  :app:testDebugUnitTest \
  :app:assembleDebug

SHA-256: shasum -a 256 app-debug.apk (macOS) or sha256sum app-debug.apk (Linux/Termux).

Provenance and safety

Evidence ≠ verification. This page stores user-entered evidence without judging its authenticity. Never treat an uploaded screenshot, status label, or artifact filename as proof of an APK's integrity or device compatibility.

No backend. No credential collection. No paid services, autonomous job launch, Git operations or publishing. Storage: browser localStorage; clear it from this page or browser settings.
